# IDENTA - ROPA PERSONALIZADA

Sitio web oficial de Identa, una tienda online dedicada a la venta de indumentaria y prendas personalizadas. El sitio cuenta con una estructura base organizada para navegar entre catálogo, contacto y redes sociales.

**Lista de Tecnologías**

1. HTML5
2. CSS3
3. Git y GitHub
4. Visual Studio

## Cómo empezar

1. Clickear enlace en "About" (si está disponible en el repositorio)
2. Clonar el repositorio y ejecutar archivo index.html en tu navegador web para visualizar la tienda.

## Flujo de Trabajo y Colaboración
Este repositorio siguió un flujo de trabajo profesional basado en **Feature Branching**. La evolución del catálogo y las mejoras semánticas de la entrega final se desarrollaron sobre ramas independientes (`feat/catalogo-y-logos`), registrando los cambios mediante commits descriptivos, publicando el contenido en remoto y completando la integración mediante la revisión de un **Pull Request** hacia la rama principal `main`.

## Limpieza del Repositorio
El proyecto cuenta con un archivo `.gitignore` correctamente configurado para evitar la subida de archivos temporales de sistema o configuraciones locales del editor de código, asegurando un entorno de producción limpio.
